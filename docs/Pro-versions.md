# Pro versions

Every plug-in also comes as **"<Name> Pro"** (Chord-Cat Pro, Vortex Pro, Glide-Cat Pro ...). It is the **same plug-in with the same sound and the same presets**, with a plain panel instead of the artwork:

- **Every parameter** in one list, also the ones the artwork keeps out of sight, with its **exact value**. Double-click a value to type a number; the little arrow sets it back to its default.
- **Search** the parameters, show **only the changed ones**, filter by group.
- **The numbers of the moment:** CPU (now and peak), how long a block takes, sample rate and latency, the output's peak and RMS (and the input's, for effects), MIDI events in / out a second, how many parameters are changed.
- **A / B**: two settings to compare, and copy one to the other. **Undo** for reset / paste / preset changes. **Copy / Paste** the whole setting (to another copy of the plug-in). **Reset all**.
- The presets with < > buttons.

A Pro version is a separate plug-in (its own ID), so you can have both, and a project that uses one keeps using that one. It is a little lighter on the computer (no animations).

**Getting them:** Cat Suite Setup > **PRO VERSIONS** (tick the ones you want). In the Windows zip they are in the folder **VST3 Pro** (copy them into your VST3 folder by hand); on Linux `./install.sh --pro`. The Mac download doesn't have them yet.
