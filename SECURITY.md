# Security Policy

## Supported versions

Security fixes always go into the latest release. Older versions are supported too,
but the fastest way to get a fix is to update; Cat Suite Setup can update everything for you.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ✅        |

## What's in scope

- The Cat plug-ins (VST3 and standalone) and the apps (Cat Hub, Cat Ocean, Cat Box, …)
- Cat Suite Setup (the installer and updater)
- The Cat Box network link and the Cat Link bus
- How Cat Ocean handles your YouTube stream key and the live chat

## Reporting a vulnerability

Please **don't report security problems in public Issues.**

Report them privately on GitHub instead: **Security → Report a vulnerability** in this repository.

Please include:
- what the problem is
- steps to reproduce it
- which Cat and which version (or commit) you were using

## What happens next

Cat Suite is made by one person in their free time, so these are goals, not guarantees:

1. I'll try to confirm I got your report within a few days.
2. I'll let you know whether it's a real problem and how I plan to fix it.
3. When the fix is released, I'll credit you in the release notes (unless you'd rather not be named).

Thank you for helping keep Cat Suite safe! 🐾
